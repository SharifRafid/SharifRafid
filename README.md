I'm a generalist engineer from Bangladesh 🇧🇩 who has been shipping production software since 2017 — native Android first, then everything around it: Flutter and iOS, Next.js/React frontends, Node.js and Python backends, embedded firmware, and more recently LLM-powered agents and the infrastructure that runs all of it.

I run **[DUBD (Developer Unknown Bangladesh)](https://dubd.site)**, a small full-spectrum software & hardware studio. We take products from idea to prototype to production for startups, agencies, and government clients — web, mobile, desktop, IoT, and AI.

**Right now I'm moving toward DevOps and platform engineering** — containers, CI/CD, cloud architecture, observability, and making deployments boring — while still building apps, agents, and backends every week.

## 🔭 What I'm doing now

- 🛠️ **Building** AI-assisted products: LLM integrations, RAG systems, tool-using agents, and automation pipelines that replace manual workflows
- ☸️ **Going deep on** DevOps — Docker, CI/CD, cloud infra on AWS & DigitalOcean, Kubernetes, infrastructure-as-code, and monitoring
- 📱 **Still shipping** mobile: Flutter apps, native Android (kiosk / lock-task launchers, accessibility-service automation, BLE & IoT integrations), and app security audits against OWASP MASVS
- 🤝 **Open to** collaborating on open-source Android/Flutter libraries, agent tooling, and infra projects
- 💬 **Ask me about** Android internals, Flutter, Next.js, Node/Express, Firebase, LLM app architecture, or getting a messy deployment under control
